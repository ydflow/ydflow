### 🧠 我在做什么

我做 **AI Agent**：重点在让 Agent **可靠地执行多步任务**，而不只是回答问题。

- 🧩 **Agent 能力落地** — 把 Skill、工具调用、状态管理做成可复用的执行单元
- 🔧 **工具与工作流** — 从单轮对话到 plan → act → observe 的完整闭环
- 📐 **可信与可观测** — 权限边界、回滚与审计，是 Agent 能上线的前提
- 🌱 **持续跟踪前沿** — AgentScope · Qwen-Agent · trae-agent · page-agent · ZCode · open-agent-auth
